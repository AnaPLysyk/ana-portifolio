# Portfólio — Ana Paula de Lima Lysyk

Aplicação web do portfólio profissional, construída a partir do protótipo visual validado.

## Stack planejada

- React
- TypeScript
- Vite
- CSS responsivo
- API e backend em etapa posterior
- PostgreSQL em etapa posterior

O desenvolvimento do front-end será feito primeiro, preservando o layout, os estados de tema, navegação, assistente e edição definidos no protótipo.
